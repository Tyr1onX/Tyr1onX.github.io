# Tyr1onX

Tyr1onX 的个人入口：项目、记录，以及正在被做出来的想法。

## First version

第一版保持克制，只包含：

- 有记忆点的单页首屏
- 当前正在投入的项目与学习方向
- 三个精选作品入口
- 最近记录与个人链接
- 响应式布局、深浅色主题和轻量滚动动效

## Local preview

这是一个无依赖的静态站点。克隆仓库后，可直接打开 `index.html`，或使用任意静态文件服务器预览。

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## Deployment

仓库合并到 `main` 后，可在 GitHub Pages 中选择从 `main` 分支根目录部署。
